# HyperDragShare · HyperOS 4 适配分支

这是基于 HyperDragShare 代码继续开发的独立 fork，目标是在小米 HyperOS 4 上增强文字和图片拖拽分享。项目按本分支代码和适配目标维护；MI Big Bang APK 与 BigBang/NovaText 项目只作为行为和技术分析参考，不作为本项目的需求清单。

当前适配目标是 Xiaomi 15 Pro、HyperOS 4.0.0.17、Android 17。设备已安装 1.7.130（versionCode 154），传送门注入与 Root 握手均为 154。197 项单测、Lint 和构建通过；功能的实际操作结果与未验收范围分别记录。

## 当前开发状态

- 新增可选“游戏内暂停自动触发”，默认关闭，按 Android 声明的游戏分类生效；手动点取和 OCR 仍可用。设置保存和非游戏来源已验证；本机没有声明该分类的应用，真实游戏内手势仍待验收。
- 四种拖拽外观统一跟随触达的屏幕边缘。1.7.122修复现代样式换边后旧窗口未释放的问题，受控真机换边/离开重开/取消通过；130修复简洁/流光快速离开后换边取消的旧菜单残留，以及流光重入光效继续收缩。均有修复前失败、修复后通过的设备证据；真实传送门拖拽仅右边、底边有近期证据，其余组合仍需逐项验收。
- 面积预热和主动点取改为共用模块持有的取词连接，手动选点期间暂停自动请求。两进程复用、关闭后继续取词及进程退出释放已验证；真实面积仍未取得有效输入。
- 新增控制中心“点取内容”：点选当前页面的文字或图片，再在原页操作，不占用普通长按。设置页可申请添加磁贴；生成文字、图片和 bilipai 提醒标题已通过，评论区尚未验证。详见 [点取说明](docs/POINT_CAPTURE.md)。
- 中转站默认使用不超过窗口六分之一的取用窗，可收为灰色侧条，也可主动放大为 HyperOS 系统小窗。独立应用已实际接收文字、图片和混合内容拖出；具体应用的兼容性仍需验证。
- 多次收集的文字和图片可多选分组、拆开，组卡预览正文和图片；同次导入的多张图片合为一张卡片，长按整组拖出、点开逐张取用。1.7.124已接入系统小窗和管理页；侧窗放大保留当前图片组。窄窗搜索按需展开，多选操作固定可见。原生小窗分组/返回/搜索/删除已验证，跨应用接收尚未验证。数据格式沿用123；回退128及更早前先拆开文字/混合组，回退122及更早APK还需配套数据备份，见 [中转站说明](docs/STASH.md)。
- 文字和图片复制共用成功/失败反馈。1.7.120 已验证侧窗、系统小窗复制图片，另一应用读取字节一致；删除原中转站条目后，剪贴板副本仍可读取。副本沿用图片暂存缓存期限，不承诺永久保留。
- 图片、整屏和选区识字可选择 ML Kit 或系统 AICR V2。AICR“查找原文附近文字”按已核验的位置预选邻近内容，1.7.128确认后将上方文字插在原文前，其余接在末尾，保留原合并词块与选词；同时避免预选远处状态栏。原页结果、分词和区域追加已有真机证据；复杂页面、并发和识别质量仍有待验项。小爱私有识屏调用链未接入，能力查询 Provider 不是 OCR 接口。
- 分词、搜索、词典和翻译使用原页浮窗，已验证选词、编辑、合并、复制、中文翻译、键盘返回和恢复选择；透明 Activity 只保留部分接收入口。二维码图片可在原页识别、复制并打开 HTTPS 结果。
- 页面统一接入 Miuix 主题，可跟随系统深浅色。存活分词窗口切换主题已有证据；其他页面、横屏和全部动画仍待验收。
- AICR 文本直取、背部轻敲有精确作用域 Hook；实际动作证据见设备记录。拇指面积触发、bilipai 评论普通长按仍未解决；旧侧条 ANR 未找到根因。参考应用同机能面积触发，不能据目前零数据断言硬件不支持。

## 使用要求

- Android 13 或更高版本；本分支主要面向 Android 17。
- 已安装 LSPosed 并启用模块，作用域选择 `com.miui.contentextension`；启用 AICR 文本直取时再加入 `com.xiaomi.aicr`，启用背部轻敲时再加入 `android`。
- Root 权限用于读取触摸设备输入，使预览在同一拖拽手势中跟随手指。
- 当前安装版本、逐项真机证据和待验收清单见 [设备验证记录](docs/DEVICE_VALIDATION.md)。中转站实现和功能边界见 [中转站说明](docs/STASH.md)。

## 构建

构建与本地测试使用 JDK 21，Java/Kotlin 输出目标为 17。Windows 下运行：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。
