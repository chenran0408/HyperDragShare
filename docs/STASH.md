## 当前代码

- `StashStore` 在应用私有 SQLite 中保存条目，图片复制进 `files/stash`，不依赖临时分享图片的过期时间。列表按新到旧排列。
- 传送门拖拽菜单的内置“中转站”经限定调用方的 Provider RPC 存入；该路径接通，尚需真实传送门拖拽验收。
- 设置、磁贴和传送门目标复用同一原页Miuix托盘；系统分享使用透明接收桥，保存仅显示侧条。点内容进行分词/预览，长按内容直接拖；没有完整管理页、复制或搜索入口。
- 多选支持当前范围全选/取消、明确清空选择、分组/拆开及确认移除；按住已选内容拖出全部有序选区。ClipData文字/图片及混合项目按托盘顺序传递，具体接收支持仍逐应用确认。
- 持久图片 Provider 不导出，外部接收者必须获得用户本次分享/拖拽所给的 URI grant。对不存在的条目、读取失败和权限失败给出明确原因，不改变系统组件权限。
- 透明接收桥串行导入，单项图片限制32MiB；超限给出原因并清理不完整文件。批量图片共用批次，失败撤销本批生成记录；不动原有条目。失败权限与复杂分享实机边界见DEVICE_VALIDATION。
