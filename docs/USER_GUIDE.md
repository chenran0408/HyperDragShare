# MMGG 使用指南

MMGG 面向已经取得Root并安装LSPosed的小米用户。它提供原页选词、图片识字、内容拖放、临时中转站与手势设置；系统与机型适用范围见[项目介绍](../MMGG.md)。

## 启用与设置

安装适合自己版本、签名一致的APK，在LSPosed启用模块并勾选推荐作用域，授予Root与悬浮窗权限。首次启用按提示重启；后续更新若只涉及应用作用域，可使用“通用设置→重载模块”。系统框架代码更新仍需软重启或整机重启。

首页异常卡与诊断页会区分权限、注入、服务和输入；“暂时无法确认”不等于没有授权。设置可用顶部搜索定位。保存后的提示会说明生效时机和相关作用域。

## 按住选词

单指静止按住文字，出现分词面板后点选或滑选词块，再复制、搜索、查词、分享或加入中转站；按住已选内容可拖出。全选、拆词、合并和撤销保留原有入口；部分选中操作在“更多”中。

关闭搜索或查词结果后可回到原分词面板。按住触发以时长和位移判断，不测量真实触摸面积；确认时间可在设置调整。

## 图片、识字与扫码

按住图片并拖向边缘，从菜单选择识字、扫码或分享目标。识字和扫码使用系统AICR服务，服务缺失、不可用或连接失败会给出提示。

微信局部识字可能使用当前屏幕区域截图；它不等于媒体原文件。来源未确认的截图不会冒充原图拖出。实际版本的原媒体能力和限制见[当前状态](CURRENT_STATUS.md)。

## 临时中转站

从分词或图片菜单存入内容，再从已有中转站入口或支持的原生侧栏打开。按住内容可拖出，多选文字可合成一条；取消拖动保留内容和选区，收起后移除窗口，不留旧灰条。图文混选不受支持时需分别操作。

接收应用决定拖入内容后如何处理；聊天应用可能直接发送，请先使用无私人内容的测试场景。中转站保存的是本地暂存数据，卸载会删除；当前版本接收与发送的待验情况见[当前状态](CURRENT_STATUS.md)，不能仅凭“拖出成功”判断发送成功。

## 复制直达与手势

复制网址、邮箱或电话后，可通过原生复制卡片/提醒取用；网页可以指定浏览器，不会自动打开或发送内容。通知权限与频道悬浮提醒是不同设置。

“手势增强”管理底角、蜂巢、侧滑目标；“小窗增强”管理尺寸、位置与窗外点击。侧滑与系统侧栏同时启用时留意冲突；游戏避让和黑名单可减少干扰。

## 下载与更新

[下载正式版](https://github.com/chenran0408/MMGG/releases/latest)。Beta用于测试，签名相同且versionCode满足升级要求才能覆盖保留配置；不要卸载或清数据强行切换，也不要直接装回旧包。发布规则见[版本线说明](RELEASE_CHANNELS.md)。

其他机型、ROM与未覆盖交互不能保证相同行为。小米翻译内部服务尚未接入；既有翻译入口沿用原方式。项目来源与许可见[致谢](ACKNOWLEDGEMENTS.md)。
