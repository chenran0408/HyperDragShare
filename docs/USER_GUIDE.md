# MMGG 第一代：在原页面选词、拖图、随手取用

**Make Mi Great Genesis，让小米伟大重生。**

MMGG 面向已经 Root 并安装 LSPosed 的小米用户。当前验证环境是小米 15 Pro、HyperOS 4.0.0.17、Android 17。日常功能在原应用上方使用，只有调整设置需要打开 MMGG。

## 先启用，再回到原应用

安装正式版 APK，在 LSPosed 启用 MMGG 并勾选推荐作用域，授予 Root 与悬浮窗权限。首次启用按提示重启；首页显示“已激活”后即可使用。四个设置模块分别是传送门与大爆炸、手势增强、小窗增强、复制直达；找不到设置时，用顶部搜索。

<img src="images/mmgg-home.png" width="300" alt="MMGG 设置首页" />

## 按住文字，选完就用

单指静止按住文字，呼出分词浮窗。点选或划选需要的词，直接复制、搜索、查词；按住选区可拖出。

- **全选 → 拆词**：把长句拆细，也可只拆选中的部分。
- **合并、撤销**：重新组合词块，操作错了可以退回。
- **加入中转站**：暂存选区；未选词时暂存全文。

工具分为两排图标，长按可查看说明。点击窗口外收起；关闭搜索或查词结果后，回到保留选区的分词面板。

<img src="images/mmgg-words.png" width="300" alt="MMGG 原页分词与两排常用工具" />

## 复制网址，直接取用

开启“复制直达”后，系统识别到网址、邮箱或电话时，沿用原生复制直达卡片。MMGG 去掉该卡片的应用商店安装推广，保留打开内容和分词操作；网址可以使用自己选定的浏览器。不会自动打开链接或发送内容。

在 MMGG 自己的搜索、查词窗口中复制，不再重复弹出卡片。系统无法识别的内容不保证出现卡片。

<img src="images/mmgg-copy-card.png" width="300" alt="去除应用商店推广后的系统原生复制直达卡片" />

## 图片拖到边缘，识字、扫码或分享

按住图片后向屏幕边缘移动，出现菜单后选择识字、扫码或目标应用。图片和屏幕识字使用手机自带 AICR 服务；扫码同样复用系统能力，不需要在 MMGG 内另下识别模型。系统服务不可用时会提示原因。

微信缺少可读文字时会识别当前可见区域，因此取得的区域截图不一定等于原始图片文件。

## 中转站，临时收集再拖走

从分词面板或图片菜单加入内容，点灰色侧条展开中转站。拖动侧条或标题可移动，松手就近贴边；按住内容直接拖到其他应用，多选后可整组拖出。收起与取消拖动会保留内容和选区。

中转站是临时拖放工具，展开最多占屏幕六分之一。接收应用决定是否接受拖入内容；**拖进聊天应用可能直接发送，请先在文件传输助手试用。** 卸载应用会删除本地暂存数据。

## 底角手势与小窗

在“手势增强”选择底角动作、应用、快捷方式和蜂巢目标；小窗打开后的尺寸、位置和窗外操作统一在“小窗增强”调整。边缘侧滑交给系统原生侧栏，避免两套手势抢操作。

游戏里不想误触，可使用游戏避让和应用黑名单，也能手动添加应用。

## 下载与使用提醒

[下载 MMGG 正式版](https://github.com/chenran0408/HyperDragShare/releases/latest)。只提供 arm64-v8a，使用 R8 压缩；原 HyperDragShare fork 用户可直接覆盖安装，包名和配置保留。更新后若提示旧版本仍在运行，使用设置里的作用域重载；系统框架更新仍需软重启或整机重启。

其他机型与系统版本尚未逐一验证。现有翻译入口沿用原方式，小米翻译内部接口尚未接入。
