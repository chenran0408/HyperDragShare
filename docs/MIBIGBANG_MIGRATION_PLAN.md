# MI Big Bang 功能迁移矩阵

本文是 HyperDragShare 自己的迁移计划。MI Big Bang APK 只用于确认行为和进程入口；产品需求、实现边界和最终 UI 以本 fork 与 Xiaomi 15 Pro / HyperOS 4 为准。

## 参考物与证据边界

- 参考 APK：用户提供的 `mibigbang.apk`，版本 `1.7.0`，SHA-256：`5c18d11b3169ced658809039473320fa7d0f6eaac05dec393e739c24b362441d`。
- 静态工具：JADX 1.5.6；APK 声明了传送门、AICR、`android` 系统进程、快捷设置、语音服务、区域固定和链接面板组件。
- JADX 处理了 3,603 个类，报告 103 个反编译错误。下列结论限于可读代码、Manifest、资源和 DEX 字符串；不能据此声称所有运行路径已验证。
- 目标设备：Xiaomi 15 Pro / HyperOS 4.0.0.17 / Android 17。安装与运行验收尚未完成。

## 实施顺序与验收点

### 阶段 1：稳定现有功能并统一 UI

- 修复简洁/现代样式，确认四个方向触发、松手关闭、重新进入热区后可再次展开。
- 将搜索、图片 OCR、分词页、旧分词工具栏与所有设置页统一到 Miuix 主题和组件行为。
- 补齐分词页已有但未连通的操作，核对选中文本、原图 URI、二维码结果和系统返回状态。
- 验收：`testDebugUnitTest`、`lintDebug`、`assembleDebug` 通过；设备上逐项操作四种样式和文字/图片基础链路。

### 阶段 2：屏幕 OCR、快捷设置入口与区域操作

- 新增明确由用户点击启动的快捷设置 tile。
- 使用现有 Root 截图通道在前台显式启动后取屏幕帧，离开锁屏/安全窗口时拒绝处理。
- OCR 结果进入 Miuix 可选文本列表，支持点选后分词/复制/搜索；后续再加入区域固定与 QR 元数据。
- 验收：截图只在用户点 tile/背敲时发生；无障碍事件回调中不截图、不持续读节点。

### 阶段 3：系统 Hook 和 AICR 集成

- 将 LSPosed 作用域从仅传送门扩展为传送门、AICR 与 `android`，不加入 `com.miui.contentcatcher`。
- AICR Hook 只处理可确认的文本直取/复制调用；参数不匹配或 provider 不存在时原样放行。
- 系统 Hook 只针对 `MiuiBackTapGestureService` 及其双击/三击回调；不在后台强行常驻或重注册系统传感器。
- 背敲功能默认关闭，系统进程从受限 Provider 读取单一模式；任何 Hook 异常都放行 ROM 原行为。
- 验收：先在目标 ROM 确认类/方法/参数签名，再逐项测试默认关闭、双击、三击和 ROM 原快捷动作。

### 阶段 4：OCR 引擎与更多细节

- 抽出 OCR provider 接口，保留本地 ML Kit；在线引擎按可用 API 接入 OCR.space、百度、腾讯、有道和可选 AI 视觉。
- 引擎配置、请求超时、错误恢复和隐私说明放入 Miuix 设置；凭据只保存在本地受保护偏好中。
- 增加屏幕/区域 OCR 的缩放切片与行序恢复；只有在识别质量/耗时可测后才默认启用。
- 验收：无凭据时本地识别仍完整工作；单个在线服务失败不影响其它引擎。

### 阶段 5：可选系统语音能力和维护

- 评估语音交互/识别服务是否能以普通应用身份安全提供；如需用户设为系统助手，必须由用户主动设置且默认关闭。
- 加入 JobScheduler 图片清理任务，设置期限和路径白名单，仅处理本模块生成的文件。
- 验收：服务未被用户启用时不启动；清理仅删除达到保留期且属于本模块的文件。
