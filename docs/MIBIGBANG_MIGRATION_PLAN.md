# HyperDragShare 功能对照与迁移记录

本表用于推动 HyperDragShare 自己的功能开发。MI Big Bang APK 与演示视频只作为行为证据；本项目继续以 HyperDragShare 为基础独立演进，不沿用参考项目的 README、产品结构或代码。

## 证据边界

- APK：用户提供的 MI Big Bang 1.7.0，SHA-256 5c18d11b3169ced658809039473320fa7d0f6eaac05dec393e739c24b362441d。JADX 1.5.6 可读 3,603 个类，另有 103 个反编译失败；APK 清单、字符串和反编译代码只作静态证据。
- 视频：用户提供的 mmexport1792496604326.mp4，约 3 分 40 秒。可直接观察到设置页与文本分词流程；视频没有展示的能力不按“已验证”记录。
- 目标机：Xiaomi 15 Pro（2410DPN6CC）、HyperOS 4.0.0.17.XOBCNXM（V816/816）、Android 17/API 37。MI Big Bang 已卸载；Root 已授权，SELinux enforcing；小爱 8.3.30.4420 与 AICR 4.12.26 已安装。当前设备已安装1.7.141（165）；传送门仍运行164，未为本轮Hook切走用户当前页面或重启框架。面积输入尚无有效真实样本；不将普通按住、注入日志或旧版方向截图作为当前全部通过的证据。

状态标签：**源码已接通**表示能从当前代码定位到实现，不代表目标机通过；**用户/视频确认**只表示有对应行为证据；**有缺陷**表示已知不能工作；**缺失**表示尚未实现；**待实机验收**表示当前无法仅靠静态检查定论。
