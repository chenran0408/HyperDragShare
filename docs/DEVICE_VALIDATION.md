## 运行规则与已排除的误判

- 安装后先核对版本；启动面板后先看实际前景，再操作坐标。设备前景可能被用户切换，启动记录不等于面板仍在前景。
- Android 剪贴板无可用 shell 命令；用实际输入框粘贴核验，不猜测 Binder 事务号。
- 选词图标问题来自整张 PNG 染色；拆分颜色问题来自 View 重建后遗漏主题刷新，均已通过真实行为定位和修正。
- Hook 安装日志只证明安装；不能代替拖拽、背敲与 OCR 动作验收。
