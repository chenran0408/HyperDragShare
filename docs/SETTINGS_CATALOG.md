# 设置目录与搜索

179 将原首页、拖拽、更多及手势七个分页改成四个同级模块，公共事项单独放入通用设置。复用同一 NavDisplay，不增加 Activity。

| 旧归属 | 当前归属 |
|---|---|
| 首页按住取词、避让；更多中的识字、背敲 | 传送门与大爆炸 › 触发与识别、应用避让 |
| 首页分词开关、预加载 | 传送门与大爆炸 › 分词与取用 |
| 拖拽页内容、分享目标、外观、触摸、滚动 | 传送门与大爆炸 › 拖拽分享及相关参数 |
| 首页侧边中转站、图片暂存说明 | 传送门与大爆炸 › 中转站 |
| 手势通用、底角、侧滑、蜂巢、任务、动效 | 手势增强 |
| 手势窗口页尺寸、位置、窗外点击 | 小窗增强 |
| 更多中的复制直达、浏览器 | 复制直达 |
| 主题、应用显示、权限、重载、日志、报告、关于 | 通用设置 |

`SettingsCatalog.kt` 定义轻量的 `SettingEntry`。设置构建函数在注册控件时一并提供标题、归属、关键词、稳定标识和启用条件；页面与搜索直接消费同一组条目，不再维护第二张搜索索引。原偏好键和保存方式保留；旧 OCR 选择键停止使用，其余配置不迁移、不重置。

首页搜索完全离线，支持标题、路径、关键词和常用别称。模块内每个条目都有稳定 key；搜索结果导航时携带该 key，按包含分组标题的实际列表顺序滚动并短暂高亮。关闭的设置仍注册，显示前置条件；搜索不会启用它。目标应用、黑名单等已有管理页可由结果直接进入。

搜索词和结果列表状态放在导航宿主中；进入设置后返回，不重新清空查询或重置结果位置。更换查询才回到结果顶部。

设置使用现有 Miuix 0.9.3。条目统一由页面提供 22dp 分组图标，控件继续使用 Miuix Preference；主设置保留文字名称，避免只显示难辨图标。分词、识字和中转站仍是原页浮窗。

检查更新位于通用设置的关于组。只在用户打开时查询公开仓库正式Release，显示版本与说明；只下载arm64包，下载完成后由用户点击交给系统安装器。安装前核对所属版本、包名与版本号，系统负责证书与安装授权；不自动降级。独立FileProvider仅开放应用外部文件目录的Download子目录，与图文分享Provider分开。

验证与安装以 `CURRENT_STATUS.md` 的179记录为准；本文件是实现说明，不代表已完成真机验收。

Root用户精简：首次指南保留启用、取词、拖放三步；删去重复的Root/面积科普。模块页面对未满足前置开关的从属参数收起，避免常驻无效控件；目录仍完整保留，搜索直达时单独展示该行及前置条件，不自动开启功能。加载中临时禁用的操作没有前置条件，因此不会被隐藏。悬浮窗权限入口显示当前授权状态，保留真实权限边界。

187 起产品只支持 Root＋LSPosed：删除系统无障碍服务声明、启动状态和“传送门／无障碍”设置，长按取词固定使用传送门 Hook 与 Root helper。Root helper 内部的 `UiAutomation` 节点读取和节点分类器继续保留，它们不是系统无障碍服务，也不要求用户开启无障碍。
